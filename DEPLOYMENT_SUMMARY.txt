REQUIRED CLOUDFLARE RESOURCES
------------------------------
1. D1 Database: painel-parceiroai-db
2. KV Namespace: CACHE (production)
3. Worker: painel-parceiroai-prod
4. Pages Project: painel-parceiroai

REQUIRED SECRETS
----------------
Set these secrets in Cloudflare:
- WEBHOOK_SECRET: HMAC secret for n8n webhooks
- VALID_API_KEYS: Comma-separated API keys for authentication
- CHATWOOT_TOKEN: Bearer token for Chatwoot integration

CUSTOM DOMAIN CONFIGURATION
----------------------------
After deployment, configure these custom domains in Cloudflare Dashboard:

1. Frontend (painel.clubemkt.digital):
   - Go to Workers & Pages > painel-parceiroai
   - Add custom domain: painel.clubemkt.digital

2. API (api.painel.clubemkt.digital):
   - Go to Workers & Pages > painel-parceiroai-prod
   - Settings > Triggers > Custom Domains
   - Add custom domain: api.painel.clubemkt.digital

DNS records will be automatically configured by Cloudflare.
